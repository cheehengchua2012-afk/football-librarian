Privacy Policy – Football Librarian

Last updated: 22 November 2026

Who uses this app

Football Librarian is a personal tool used only by its owner. It is not available to other users.

What data it accesses

With the owner's permission, the app accesses the owner's own Google Drive files and Google Sheets in order to rename, upload and catalog football video files.

How data is used

  • Data is used only to organise the owner's own footage library.
  • No data is sold, shared with third parties, or used for advertising.
  • No data from any other person is collected.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Questions can be raised via the project's GitHub issues page.
